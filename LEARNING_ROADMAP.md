# Six-Semester Learning Roadmap

A flexible plan for building skills alongside the BCA AI and Data Science degree. Adjust it to match the university syllabus and project opportunities.

## Semester 1 — Foundations

- Strengthen programming fundamentals and problem solving.
- Learn Git, GitHub, Linux command-line basics, and clear technical documentation.
- Complete coursework projects and publish well-described repositories.

## Semester 2 — Core Programming and Data

- Develop Python fluency and practice data structures and algorithms.
- Learn SQL and relational database fundamentals.
- Build a small data-focused application and document setup and usage.

## Semester 3 — Mathematics and Machine Learning

- Study statistics, linear algebra, and machine-learning foundations as covered in coursework.
- Practice data cleaning, visualization, and model evaluation.
- Complete an end-to-end introductory ML project.

## Semester 4 — Applied AI

- Explore deep-learning concepts and responsible AI practices.
- Build an application that uses a model or an AI API, with clear attribution and safety considerations.
- Improve testing, collaboration, and project documentation.

## Semester 5 — Generative AI and Specialization

- Deepen knowledge of generative AI, embeddings, retrieval-augmented generation, and prompt engineering.
- Build and evaluate a small RAG project using suitable public or permitted data.
- Seek an internship, research opportunity, or open-source contribution.

## Semester 6 — Portfolio and Career Preparation

- Polish selected projects and explain design choices, results, and limitations.
- Prepare a final-year project aligned with AI and Data Science interests.
- Practice technical interviews and apply for suitable internships or entry-level roles.
