## Semester 1 — Foundations (current)

**KRMU subjects in the published handbook:** Mathematics for Modern Computing Applications; Foundations of Web Development; Problem Solving with Python; Essentials of Computer Science and Career Skills; Data Visualization with Power BI; Environmental Studies; Foundations of Data-Driven Decision Making.

**Skills to build:** Python fundamentals, problem decomposition, basic web concepts, spreadsheets/data visualization, Git/GitHub, and command-line basics.

**Project milestone:** Complete a small Python console project and organize coursework and setup instructions in GitHub. Keep project claims and progress accurate.

**Credential target:** Build a Python practice record. Consider an introductory Python credential only if it is available through the university or a suitable free/low-cost course.

**Weekly habit:** Aim for about three hours of focused practice outside scheduled classes, adjusted around coursework and exams.

## Semester 2 — Data Structures and Practical Computing

**KRMU subjects:** Essentials of Data Structures; Introduction to Discrete Mathematics; Interactive Front-End Development; Cloud Computing; Introduction to Design Thinking and Prototyping; an Open Elective; Minor Project-I.

**Skills to build:** Python data structures, algorithmic thinking, JavaScript/HTML/CSS fundamentals, and introductory cloud concepts.

**Project milestone:** Create a documented data-structures repository implementing at least five structures or algorithms studied in class, with examples and simple checks.

**Credential target:** Consider a Python or data-structures course certificate through SWAYAM/NPTEL if a relevant course is offered and fits the semester workload.

## Semester 3 — Algorithms and Applied Data Science

**KRMU subjects:** Analysis and Design of Algorithms; Back-End Web Development; Foundations of Practical Data Science; Open Elective-II; Verbal Ability; Summer Internship-I; Competitive Coding-I; Community Service; VAC-II.

**Skills to build:** Complexity analysis, backend fundamentals, data cleaning, exploratory analysis, and clear technical communication.

**Project milestone:** Publish a reproducible analysis of a public dataset with a notebook, charts, setup notes, and a short explanation of limitations.

**Career target:** Prepare a focused CV and begin exploring internship opportunities through the university and professional network.

**Credential target:** Prefer a course-aligned learning credential or a completed project over collecting unrelated certificates.

## Semester 4 — Databases and Statistical Analysis

**KRMU subjects:** Essentials of Object-Oriented Programming with Java; Fundamentals of Database Management Systems; Applied Statistics for Data Analysis; Open Elective-III; Communication and Personality Development; Minor Project-II; Competitive Coding-II; Club/Society; VAC-III.

**Skills to build:** SQL and relational design, object-oriented programming, statistical reasoning, and structured project work.

**Project milestone:** Build a small data application that stores and queries information with a relational database, then presents a useful summary or visualization.

**Career target:** Apply for suitable internships and ask faculty or seniors for feedback on the project and CV.

**Credential target:** Complete a database or statistics course only if it complements current university work and has a manageable cost and schedule.

## Semester 5 — Data Science and AI/ML Specialisation

**KRMU subjects:** Foundations of Operating Systems; System Design Essentials; Machine Learning Fundamentals; Big Data Processing and Cloud-Based Analytics; Arithmetic and Reasoning Skills; Summer Internship-II; Competitive Coding-III.

**Skills to build:** NumPy, pandas, model training and evaluation, data pipelines, cloud-based analytics, and responsible use of AI.

**Project milestone:** Build two scoped projects: one machine-learning project with a documented evaluation, and one data pipeline or analytics project. Keep datasets public or otherwise permitted.

**Personal project idea:** A campus study assistant that answers questions from course notes using retrieval-augmented generation and points back to the source passages. This idea builds on Maulik's stated interest in the Generative AI and RAG workshop.

**Career target:** Pursue an internship or supervised project related to data analytics, AI, or machine learning.

**Credential target:** Choose one relevant AI/ML credential after reviewing the semester's coursework, cost, and prerequisites.

## Semester 6 — Applied AI and Career Readiness

**KRMU subjects:** Introduction to Computer Networks; Agile Software Engineering Essentials; Deep Dive into Machine Learning Techniques; Generative Models and Applications; Comprehensive Placement Preparation; Minor Project-III; Competitive Coding-IV.

**Skills to build:** Model comparison, generative AI fundamentals, testing, collaboration, networking basics, and communicating project results.

**Project milestone:** Deliver a capstone-quality AI/data-science project with documented data sources, evaluation, limitations, and a usable demo where practical. Refine the strongest repositories and portfolio descriptions.

**Career target:** Maintain an application-ready CV and portfolio, practice technical interviews, and apply for internships or entry-level opportunities that fit the skills developed.

**Credential target:** Finish only a credential that adds clear evidence for the chosen role; do not list planned credentials as earned.
